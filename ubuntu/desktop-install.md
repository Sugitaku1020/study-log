## 手順
インストールをするとすぐにGUIの選択画面で設定をすることができる。
使用言語：日本語
キーボードレイアウト、キーボードバリアント：日本語
インターネットの接続方法：有線接続
Ubuntuでなにをするか：Ubuntuをインストール（OSと共存してUbuntuをインストール)
Ubuntuのインストール方法：対話的インストール(ほかの選択肢は自動インストールファイルによる自動化、Landscapeによる自動化)
開始時にどのアプリをインストールするか：既定の選択(最小限のwebブラウザと基本的なユーティリティ)
推奨するプロプライエタリなソフトウェアをインストールするか：なし
Ubuntuをどのようにインストールするか：ディスクを削除してUbuntuをインストールする
暗号化とファイルシステム：暗号化しない(パスフレーズで暗号化するとコンピュータ起動毎にパスフレーズを入力する必要あり)
ユーザー名やパスワードの設定
現在地/タイムゾーン：Tokyo・Asia/Tokyo
